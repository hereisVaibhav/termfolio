How to use it

  1. Create a public repo named exactly like your username, with a README.
  2. Pick each file in the “SVG file” list, then save it (terminal.svg, skills.svg …) and upload them all to that repo. Upload files, don’t paste into the editor.
  3. Replace README.md with the generated README. Commit and refresh your profile.
